# 🌱 Agro Forte - Cultivando o Futuro Sustentável

Bem-vindo ao **Agro Forte**, um website profissional, moderno e altamente interativo dedicado à educação sobre agricultura sustentável, tecnologia no campo, segurança alimentar e preservação ambiental.

## 🎯 Visão Geral

Agro Forte é uma plataforma educativa que conecta consumidores ao universo do agronegócio sustentável, demonstrando transparência, inovação e responsabilidade ambiental.

## 🚀 Instalação

### Clonar Repositório
```bash
git clone https://github.com/isabellinogueiralourenco-ui/Agroforte.git
cd Agroforte
git checkout feature/website-development
```

### Servir Localmente

**Live Server (VS Code)**
- Instale "Live Server"
- Clique direito em index.html
- Select "Open with Live Server"

**Python**
```bash
python -m http.server 8000
```

**Node.js**
```bash
npm install -g http-server && http-server
```

Acesse: `http://localhost:8000`
